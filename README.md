# 🚀 Galactic Guardians

---

## 🎮 Projekt: *2D top-down vesmírná videohra*
### *Akční hra odehrávající se ve vesmíru, kde hráč čelí vlnám nepřátel a vylepšuje svou loď.*

🛰️ Dynamický střelecký systém  
🧬 Level-up systém s výběrem vylepšení  
🌌 Nekonečné pozadí a wave systém nepřátel  
🗺️ Přehledná minimapa  
🔊 Vlastní zvukové efekty

⏱️ **Časová náročnost**: přibližně *3 týdny* volného (mimoškolního) času

---

## 🎯 Motivace

> Projekt vznikl jako **školní týmová práce**, kde jsem působil jako **DevOps a hlavní vývojář**.  
> Měl jsem na starost správu verzí, organizaci repozitáře a řešení merge requestů.  
> Zároveň jsem se významně podílel na programování klíčových herních mechanik.

---

## ✨ Funkce a vlastnosti
- 🔫 Střelecký systém a řízení střelby
- 🎮 Level-up systém s výběrem ze 3 náhodných kartiček
- 🌌 Nekonečné pozadí (parallax scrolling)
- 👾 Wave systém nepřátel s rostoucí obtížností
- 🗺️ Zobrazení minimapy
- 🔊 Vlastní zvukové efekty a mixování zvuku
- 🎲 Náhodné generování posilnění a statistik

---

## 🧠 Co jsem se naučil / použil
- 📦 Základy DevOps (verzování, týmová spolupráce přes Git)
- 🔄 Merge request management a práce v týmu přes GitHub
- 🔁 Zpracování vstupů a stavů herního objektu
- 🎮 Implementace level-up systému a generování možností

- 🔊 Práce se zvukem a efekty v Unity
- 🎨 Základy level designu a feedback loopu pro hráče

## 📝 Shrnutí

Galactic Guardians je týmový projekt, kde jsem si vyzkoušel nejen **vývoj akční 2D hry v Unity**, ale i **vedení repozitáře a vývojového workflow týmu**.  
Projekt mi pomohl rozvíjet schopnosti v oblasti **herního designu, DevOps a týmové spolupráce**, a stal se pro mě důležitou zkušeností při budování větších projektů s jasně rozdělenými rolemi.
